# Besaid Island

A small personal gaming site: https://kiwamasi.github.io/Besaid-Island/

- **Home:** game cards, each opening that game's guide.
- **Dark Cloud 2 Photography & Scoop Log:** a checklist of every Scoop, Idea and Badge, with per-chapter totals. Ticks are saved in your own browser.
- **Backlog:** games still to play, grouped by system, with search and genre filters. Anyone can make an account to keep their own.
- **Stats:** page views and recent additions.

The pages are plain HTML, CSS and JavaScript on GitHub Pages, with a small API on Netlify for accounts and backlogs.
